# Contributing

Read [development](docs/DEVELOPMENT.md), [tests](docs/TESTING.md) and
[security](docs/SECURITY.md). Use a task branch, reproduce changed behavior with a
local fixture and run `npm run validate`. Regenerate indexes and inventory with
`npm run docs:generate` and `npm run ops:doc`. Keep changes focused, credentials
private and runtime zero-dependency. Submit a PR with the final scope and validation.
